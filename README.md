A feature-rich Minecraft mod that adds many useful commands. Improve server management and give your players more fun and possibilities, or optimize your singleplayer experience - Helpful Commands works in both environments. The output is interactive and informative. It supports [LuckPerms](https://luckperms.net), and the mod is easy to configure. Commands support selectors, so you can use them on other players or entities.

## «✨» Features
* **Lots of new commands:** everything from social and fun commands to powerful management tools - all toggleable, with flexible permission control
* **Warps and homes:** create server warps and let players set custom homes - with configurable limits
* **Interactive menus and output:** hover highlighted text for more details, or click to perform certain actions
* **Selectors:** use commands on other players or entities, not just yourself
* **Flexible permissions:** compatible with [LuckPerms](https://luckperms.net). Control permissions for command arguments as well as whole commands
* **Easy configuration:** configure the mod in-game with tooltips and intuitive interactive buttons
* **Server-side:** no client installation required - players get all features just by joining a modded server
